# Shot list: jaggery-health-claims-truth

Deliberately unglamorous. This article argues against the way jaggery is
photographed as much as the way it is described, so nothing here should be
styled, back-lit or arranged on slate.

| File | Shot |
|---|---|
| `jaggery-health-claims-truth-nepal.jpg` | **Hero.** A block on a plain kitchen table in daylight. No props, no cloth, no scattered nuts. It should look like something in a house rather than something in an advert. |
| `sakhar-block-plain-table.jpg` | The same block from above, closer, showing the uneven colour and the cracked surface honestly. |
| `rashmita-at-the-kadhai.jpg` | Rashmita at the fire, working. Not posed, not smiling at the camera. This is the provenance claim, and it is the only claim on the page we make about ourselves. |

Until a file lands here the figure simply does not render, so the article can
publish before the shoot. The hero is the exception: `image` in blog.json needs
a real file, so it currently points at an existing product photograph and
should be repointed once the hero above is shot.
