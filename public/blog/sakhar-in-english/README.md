# Photographs for "Sakhar in English: What the Word Means in Nepali, Hindi and Marathi"

The page answers a translation question, and the translation is ambiguous:
in Nepali sakhar is jaggery, in Marathi it is white sugar. One photograph
that shows both side by side does that job faster than the table.

## How the slots work

The article body names every file below. A slot whose file is **not** in this
folder simply doesn't render. The photo appears on the next build the moment
the file lands here under the exact filename. No code or content changes needed.
