# Photographs for "Jaggery Powder vs Block: Which Sakhar Should You Buy?"

This is a decision page, and the decision is visual. One good comparison
photograph does more work here than the two thousand words around it.

## How the slots work

The article body names every file below. A slot whose file is **not** in this
folder simply doesn't render — the article ships without it, and the photo
appears on the next build the moment the file lands here under the exact
filename. No code or content changes needed.

Dimensions are read from the file itself, so any size or orientation works.

## Worth shooting for this page

The article has room for these and they can be added later by dropping a
figure line into the body:

- **The dissolving test, as a pair.** Two clear glasses of cold milk, a spoon
  of powder in one and a chip of block in the other, photographed after the
  same sixty seconds. The block sitting at the bottom is the single most
  useful image this page could carry, and it settles the argument the way the
  curdled-vs-smooth chiya shot does on the tea post.
- A block mid-grating on the fine side of a grater, with the pile of shavings
  next to the pouch of sieved powder. Shows the work you are paying to skip.
- The price comparison as a still life: one kilo of block and four 250g
  pouches, which is the same weight, side by side.

## A note on colour

Do not correct the two towards each other. If the powder photographs lighter
than the block, that is real and the article explains why. Matching them in
edit would make the page argue against its own photograph.
