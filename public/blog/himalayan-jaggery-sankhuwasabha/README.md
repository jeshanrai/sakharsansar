## How the slots work

The article body names every file below. A slot whose file is **not** in this
folder simply doesn't render — the article ships without it, and the photo
appears on the next build the moment the file lands here under the exact
filename. No code or content changes needed.

Dimensions are read from the file itself, so any size or orientation works.

## Before uploading

- Natural light, near a window or outdoors. Not under a yellow bulb.
- Compress every file **below 200 KB**.
- Keep the filenames exactly as above, hyphenated. Never `IMG_2043.jpg`.
- `next.config.ts` serves images with a one-year immutable cache. Replacing a
  photo later means giving it a new filename, or returning visitors keep the
  old one until their cache clears.
