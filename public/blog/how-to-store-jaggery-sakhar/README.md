# Photographs for "How to Store Sakhar So It Does Not Go Sticky or Mouldy"

A practical page. The photography should be plainly useful rather than
beautiful: a reader wants to see what the jar looks like and what mould looks
like, in a kitchen that resembles theirs.

## How the slots work

The article body names every file below. A slot whose file is **not** in this
folder simply doesn't render — the article ships without it, and the photo
appears on the next build the moment the file lands here under the exact
filename. No code or content changes needed.

Dimensions are read from the file itself, so any size or orientation works.

## Worth shooting for this page

The article has room for these and they can be added later by dropping a
figure line into the body:

- The same block on day one and after a month open on a windowsill, side by
  side, same light. This is the argument of the whole piece in one frame.
- White powdery bloom on a block next to actual grey-green mould on another,
  close and sharp. The distinction people most need help with, and the one no
  competitor has photographed honestly.
- Sakhar powder clumped solid in an opened pouch, and the same powder loose in
  a small airtight jar.
- A steel dabba with a thumbnail-loosened lid, the way it is actually kept in
  a Nepali kitchen.

## A note on the mould shot

Photograph real mould on a real block that we then throw away. Do not fake it
and do not reuse a stock image of mouldy bread. The page tells people to bin a
block on the strength of this picture, so it has to be the real thing.
